# buh-ai-tg-adapter

Telegram-адаптер к сервису [buh-ai-agent](../buh-ai-agent) — AI-агенту бухгалтерии 1С.

## Как работает

1. Пользователь отправляет сообщение боту в Telegram.
2. Адаптер пересылает его в `POST /chat` сервиса buh-ai-agent.
3. Ответ агента отправляется в Telegram ответным сообщением.
4. PDF-файлы, приложенные агентом к ответу (`files`), отправляются
   документами вслед за текстом (base64 → бинарник, лимит 50 МБ).
5. Если агент подготовил операцию (`awaiting_confirmation`), к сообщению
   добавляются inline-кнопки **✅ Подтвердить** / **❌ Отклонить**.
5. Нажатие кнопки вызывает `POST /operations/{operation_id}/confirm` или
   `.../reject` у агента. Клавиатура убирается, статус фиксируется в
   исходном сообщении.

## Запуск

```bash
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN и, при необходимости, остальные переменные
task run
```

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота из @BotFather (обязателен) |
| `AGENT_BASE_URL` | `http://127.0.0.1:8000` | Базовый URL сервиса buh-ai-agent |
| `AGENT_TIMEOUT` | `5m` | Таймаут HTTP-запросов к агенту (`/chat` может думать долго) |
| `ALLOWED_USER_IDS` | *(пусто)* | Белый список Telegram user_id через запятую; пусто — разрешено всем |
| `LOG_LEVEL` | `info` | `debug\|info\|warn\|error` |

## Сборка

```bash
task build   # бинарник в bin/buh-ai-tg-adapter
```

## Тесты

```bash
task test    # только тесты
task check   # fmt + vet + тесты
```

## Задачи

| Задача | Описание |
|---|---|
| `task run` | Запуск бота (переменные берутся из `.env`) |
| `task build` | Сборка бинарника |
| `task test` | Тесты с флагом `-race` |
| `task check` | Полная проверка: fmt, vet, тесты |
| `task fmt` | Форматирование |
| `task vet` | `go vet` |
| `task clean` | Удалить собранные артефакты |
